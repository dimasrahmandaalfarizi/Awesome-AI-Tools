For every code change:
1. Always read and adhere to the project's `CONVENTIONS.md` file.
2. Strictly follow the defined Tech Stack, Linting rules, and Testing requirements (e.g., TDD).
3. If a request contradicts the conventions, notify the user and ask for clarification before proceeding.
