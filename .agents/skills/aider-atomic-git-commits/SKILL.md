---
name: Aider: Atomic Git Commits
description: Configures Aider to make small, focused changes per commit to maintain a clean git history.
frameworks: [Aider]
---

When editing code in Aider:
1. Focus on one specific goal or file change at a time.
2. Avoid big, sweeping refactors across the entire codebase in a single prompt.
3. Ensure that every edit results in a working state before moving to the next task.
4. Use the `/architect` mode for complex, multi-file refactoring before writing code.
