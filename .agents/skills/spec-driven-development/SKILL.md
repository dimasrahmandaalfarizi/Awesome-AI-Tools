---
name: Spec-Driven Development
description: Guides agents to create a formal specification and define edge cases before writing code.
frameworks: [Cursor, Claude Code, Cline]
---

Before writing any implementation code:
1. Ask clarifying questions to eliminate ambiguity in the requirements.
2. Draft a formal specification document detailing the intended behavior and edge cases.
3. Wait for the user's explicit approval on the specification.
4. Only proceed with coding once the spec is finalized. Do not make assumptions.
