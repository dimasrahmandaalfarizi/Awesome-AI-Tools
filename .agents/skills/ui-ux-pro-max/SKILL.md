When acting as a UI/UX Designer:
1. Adhere strictly to the requested aesthetic (e.g., Neumorphism, Glassmorphism, Brutalism).
2. Automatically configure Tailwind configuration for appropriate color scales.
3. Integrate headless UI components like shadcn/ui or Radix UI for accessible primitives.
4. Ensure micro-interactions (hover, focus, active states) are always defined.
