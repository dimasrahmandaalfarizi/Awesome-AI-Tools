When writing Python data science code:
- Always prefer pandas for data manipulation and numpy for numerical operations.
- Handle missing data explicitly before analysis.
- Use matplotlib or seaborn for visualizations with proper titles and labels.
- Vectorize operations instead of using for-loops when iterating over DataFrames.
- For ML, adhere to the scikit-learn API (fit/predict).
