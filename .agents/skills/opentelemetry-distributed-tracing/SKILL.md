# OpenTelemetry Observability Protocol
1. Instrument HTTP servers and database clients using OpenTelemetry SDK.
2. Propagate traceparent and tracestate W3C headers across service boundaries.
3. Attach business context attributes to spans without logging sensitive PII.
4. Export spans and metrics via OTLP gRPC collector for minimal overhead.
