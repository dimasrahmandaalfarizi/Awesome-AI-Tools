# Contract First Development

Schema-first development with OpenAPI, Protobuf, or GraphQL before writing server or client implementations.

## Use Case
Decoupling frontend and backend teams to work in parallel against locked contracts.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Contract First Development** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
