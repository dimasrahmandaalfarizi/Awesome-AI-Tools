# Accessibility & WCAG 2.2 Guidelines
1. Ensure all interactive components are fully operable via Keyboard (Tab, Enter, Space, Escape).
2. Maintain minimum color contrast ratios (4.5:1 for normal text, 7:1 for AAA).
3. Use semantic HTML elements (<button>, <nav>, <main>) before resorting to ARIA roles.
4. Manage modal focus traps and announce dynamic state changes with aria-live.
