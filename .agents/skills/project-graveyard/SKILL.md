---
name: Project Graveyard Analyzer
description: Examines abandoned projects to diagnose code rot and create a revival roadmap.
frameworks: [Claude Code, Cursor]
---

When analyzing an old or abandoned project:
1. Scan the repository to identify the last active commit and the state of the codebase.
2. Determine the core blockers or missing features that caused development to stop.
3. Check for deprecated dependencies or code rot.
4. Provide a structured roadmap with prioritized steps on how to modernize and finish the project.
