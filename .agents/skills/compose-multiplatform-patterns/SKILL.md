# Compose Multiplatform Patterns

Kotlin Multiplatform (KMP) shared UI development across Android, iOS, Desktop, and Web using Jetpack Compose.

## Use Case
Cross-platform mobile and desktop apps sharing 90%+ code.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Copilot

## Core Engineering Rules
1. Apply the **Compose Multiplatform Patterns** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
