---
name: Test-Driven Development (TDD)
description: Strictly enforces the RED-GREEN-REFACTOR cycle for all code generation.
frameworks: [Cursor, Copilot]
---

Enforce strict Test-Driven Development (RED-GREEN-REFACTOR):
1. Write a failing test for the next piece of functionality.
2. Run the test and verify it fails (RED).
3. Write the absolute minimum amount of code required to make the test pass (GREEN).
4. Refactor the code for quality while keeping tests passing.
5. Never write implementation code without a failing test first.
