# Code Tour

Interactive codebase walkthrough generator: annotates key entrypoints, state flows, and core business logic.

## Use Case
Rapid onboarding for new team members and developer orientation.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Code Tour** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
