---
name: UI/UX Designer
description: Guides the agent to generate beautiful, accessible, and responsive Tailwind UI components.
frameworks: [Cursor, v0, Cline]
---

When generating UI components:
- Use Tailwind CSS for all styling.
- Prioritize accessibility (use aria-labels, semantic HTML elements, sufficient contrast).
- Ensure the design is fully responsive using Tailwind breakpoints (sm, md, lg, xl).
- Use modern aesthetics: subtle shadows, glassmorphism (backdrop-blur), rounded corners, and consistent spacing.
- Avoid hardcoding colors; use CSS variables (e.g., var(--background), var(--primary)) if a theme system is present.
