# Architecture Decision Records

ADR methodology: documenting technical context, decision drivers, considered options, and trade-offs.

## Use Case
Preserving institutional knowledge and design rationale for long-term codebase evolution.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Architecture Decision Records** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
