# Coding Standards

Universal clean code principles: single responsibility, small functions, strict type discipline, and self-documenting naming.

## Use Case
Establishing high code quality baselines for AI coding assistants across any language.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Coding Standards** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
