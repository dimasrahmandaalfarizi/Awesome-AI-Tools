# Code Health MCP

MCP tool exposing real-time metrics for cyclomatic complexity, test coverage, and code churn to AI agents.

## Use Case
Enabling AI agents to check code health scores during refactoring tasks.

## Supported Platforms
- Claude Code
- Antigravity

## Core Engineering Rules
1. Apply the **Code Health MCP** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
