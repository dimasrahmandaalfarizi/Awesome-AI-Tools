# Continuous Learning

Automatically capture and persist learnings from each coding session. Extract patterns, mistakes, and insights into a reusable memory file.

## Use Case
Long-running projects where agent needs to accumulate knowledge about codebase conventions and gotchas.

## Supported Platforms
- Claude Code
- Codex
- Antigravity

## Core Engineering Rules
1. Apply the **Continuous Learning** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
