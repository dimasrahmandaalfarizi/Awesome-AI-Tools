When generating frontend code:
1. Always use semantic HTML5 elements (header, main, nav, article).
2. Ensure a proper heading hierarchy (h1 -> h2 -> h3) without skipping levels.
3. Include descriptive alt attributes for all images.
4. Add appropriate meta tags for SEO and social sharing (OpenGraph, Twitter Cards).
5. Ensure fast load performance by avoiding render-blocking scripts.
