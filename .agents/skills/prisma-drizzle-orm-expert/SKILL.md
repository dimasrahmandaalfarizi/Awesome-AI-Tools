# Prisma & Drizzle ORM Best Practices
1. Keep schema migrations modular and version-controlled with reversible rollback scripts.
2. Use Drizzle ORM for latency-critical serverless edge backends.
3. Avoid N+1 relation queries by leveraging explicit joins and relation queries.
4. Enforce strict foreign key constraints and cascade rules at the database level.
