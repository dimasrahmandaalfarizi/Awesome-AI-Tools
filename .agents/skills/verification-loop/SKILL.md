# Verification Loop

Rigorous post-implementation verification: run test suites, check edge cases, inspect UI states, and validate acceptance criteria.

## Use Case
The closing phase of plan-implement-verify loop ensuring 100% working delivery.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Verification Loop** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
