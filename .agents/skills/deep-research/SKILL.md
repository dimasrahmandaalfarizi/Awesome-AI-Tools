# Deep Research

Multi-source research workflow: fetch documentation, synthesize technical tradeoffs, and verify contradictory claims.

## Use Case
Adopting unfamiliar frameworks, debugging obscure SDK quirks, or designing system architecture.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Deep Research** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
