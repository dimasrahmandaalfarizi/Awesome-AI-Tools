# Search First

Always search and read existing code before writing new code. Prevents duplication and respects existing architecture.

## Use Case
Any coding task in an existing codebase. Prevents creating duplicate functions/classes.

## Supported Platforms
- Claude Code
- Codex
- Cursor
- Antigravity
- Zed
- Copilot

## Core Engineering Rules
1. Apply the **Search First** pattern systematically before making code changes.
2. Validate outputs across supported AI harnesses (Claude Code, Codex, Antigravity, Cursor).
3. Prevent context pollution and maintain strict verification standards.
